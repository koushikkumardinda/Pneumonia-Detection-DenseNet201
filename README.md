# Explainable AI for Multi-Class Pneumonia Detection

## Overview
This repository contains the code and methodology for my M.Tech research project focused on automated medical image classification. The project demonstrates a deep learning approach to classifying chest X-ray images into three distinct categories: NORMAL, PNEUMONIA_BACTERIA, and PNEUMONIA_VIRUS. 

To ensure clinical transparency, the model integrates Explainable AI (XAI) techniques to visualize the decision-making process of the neural network.

## Methodology
* **Model Architecture:** The core model utilizes **DenseNet201** with transfer learning, leveraging weights pre-trained on ImageNet.
* **Fine-Tuning Strategy:** The classification head was trained first, followed by fine-tuning the top 50 layers of the DenseNet base using a very low learning rate (1e-5) for stable feature extraction.
* **Class Imbalance Handling:** Explicit class weights were calculated and applied during training to handle the natural imbalance between normal, bacterial, and viral X-ray samples.
* **Data Augmentation:** The training pipeline incorporates robust augmentation, including rotation, shifting, shearing, zooming, horizontal flipping, and brightness adjustments (0.8 to 1.2).
* **Interpretability (Explainable AI):** **Grad-CAM** (Gradient-weighted Class Activation Mapping) is implemented on the `conv5_block32_concat` layer to generate heatmaps. This highlights the exact regions of the chest X-ray that the model focused on to make its prediction, providing critical transparency for medical professionals.

## Dataset
The model is trained on a structured chest X-ray dataset, dynamically parsed to separate the standard 'PNEUMONIA' class into distinct 'bacteria' and 'virus' sub-classes based on filename indicators. 

## Repository Contents
* `pneumonia_detection_xai.ipynb`: The primary Jupyter Notebook containing the data pipeline, model architecture, training loop, evaluation metrics, and Grad-CAM visualization functions.
* **Outputs Generated by Code:**
  * Multi-Class Confusion Matrix
  * Training and Validation History Plots (Accuracy/Loss)
  * Grad-CAM Visualizations for each class
  * Saved Keras Model (`.keras`)

## How to Run
1. Clone this repository to your local machine or cloud environment.
2. Ensure you have the necessary dependencies installed (`tensorflow`, `numpy`, `pandas`, `matplotlib`, `seaborn`, `opencv-python`, `scikit-learn`).
3. Update the `base_dir` variable in the notebook to point to your local or cloud-mounted chest X-ray dataset.
4. Run the cells sequentially to train the model, evaluate performance, and generate Grad-CAM heatmaps.
